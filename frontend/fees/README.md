# Fees & Finance

This Vite + React TypeScript SPA powers the fees & finance workflows within the EMS platform.

## Available scripts

- `npm run dev` — start a development server on port 5177.
- `npm run build` — type-check and build the production bundle.
- `npm run preview` — preview the production build locally.

The app expects the EMS backend to be running at http://localhost:8000 and consumes APIs scoped to this domain.
